## 👋 Sobre mim

Sou **Eduardo Spiess**, fundador da **VEX**. Construo agentes de IA, automações e sistemas web para transformar processos repetitivos em software útil.

Meu foco está na interseção entre **produto, engenharia de software e IA aplicada**, criando ferramentas que economizam tempo, organizam operações e ajudam empresas a produzir mais.

```text
> build useful systems
> automate repetitive work
> connect AI to real operations
> ship, measure, improve
```
